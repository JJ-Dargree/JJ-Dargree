## What I do

- **Data quality & reconciliation** — checks that catch discrepancies between source systems and dashboards before
  they affect decisions (CTEs, `MINUS`/`EXCEPT`, layer-by-layer validation in Databricks).
- **BI validation** — Power BI values against source systems, DAX measures and Power Query transformations.
- **Software testing** — test design (RBAC, SSO/MFA), functional testing, defect management, automated scenarios with
  Playwright + pytest.
- **Tooling** — command-line tools in Python for file reconciliation, evidence classification and QA workflows.
